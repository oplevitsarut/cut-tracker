# Cut Tracker

A personal diet, workout and 16:8 fasting tracker for iPhone. It's one HTML file with no build step.

- **Home:** weight trend, deficit, zone 2 minutes, and weekly habits
- **Log:** weight, meals, workouts
- **Workout:** weekly plan, "done" button, hit/miss calendar
- **Fasting:** 16:8 start/finish timer and calendar
- **Settings:** targets, backup export/import

All data stays in the browser on the phone (localStorage). Export backups from Settings.

Apple Health import: open the page with `?weight=<kg>&active=<kcal>&date=YYYY-MM-DD` (used by an iPhone Shortcut).
